# 第1章 绪论
<!-- chapter_id: ch_1 -->

## 1.1 研究背景

随着在线测评、智能问答和多媒体交互技术的发展，心理测评系统正在从传统的静态问卷工具逐渐转向综合型智能服务。传统问卷系统通常依赖固定题目、人工解释和线下报告，能够在一定程度上保证流程规范，但在个体差异识别、过程证据记录、报告解释和后续咨询方面存在明显不足。尤其在面向普通用户的应用场景中，系统不仅需要给出分数，还需要解释分数形成的原因、提示异常作答风险，并在用户完成测评后提供可追溯、可继续讨论的分析依据。

本课题围绕 ATMR 智能心理测评系统展开。系统并不只是实现一个普通问卷网站，而是尝试将问卷作答、阶段性评分、自适应选题、异常作答检测、多智能体辩论、RAG 知识检索和视频多模态人格预测组织为一个较完整的测评闭环。其中，ATMR 问卷主线负责完成用户登录、测评会话创建、阶段答题、模块评审、综合报告和历史记录管理；视频多模态辅线则从用户上传视频中提取视觉、音频和文本线索，输出 Big Five 五维人格预测结果，并生成独立的大五人格报告。

从应用价值看，智能心理测评系统的关键不在于用模型替代专业判断，而在于为用户提供结构化、可解释和可复用的分析结果。单一问卷能够反映用户的自我报告倾向，但容易受到主观理解、作答状态和社会赞许性的影响；视频多模态线索能够提供外显行为层面的补充证据，但也存在场景依赖、样本噪声和伦理边界。因此，本文采用并列证据链的设计思路，将 ATMR 报告与 Big Five视频报告分区管理，并在咨询对话中作为上下文共同被读取，而不是把二者简单合并为一个绝对结论。

近年来，多模态人格预测研究逐渐关注从视频、音频和文本中识别人格特质。Wang 等提出的基于自适应图 Transformer 网络和多任务学习的多模态人格预测框架[[REF:1]]，通过 CLIP、Wav2CLIP、自适应图 Transformer、通道注意力融合和多任务回归头对 Big Five 人格进行预测。该研究表明，短视频中的视觉、音频和语言信息能够为人格倾向建模提供有效线索。本文借鉴其中“多模态特征提取、关联特征建模和工程化训练评估”的思路，在现有系统中实现 AGTN-MTL baseline，并将其接入在线报告流程。

## 1.2 研究意义

本文的研究意义首先体现在测评流程的工程化闭环上。一个面向实际使用的心理测评系统，不能只停留在题目展示和分数计算，还需要处理用户身份、会话恢复、阶段提交、历史报告、异常情况、报告解释和后续咨询等完整流程。本文系统基于 FastAPI和 Vue 3 构建，结合数据库持久化和接口分层，实现了从用户进入系统到完成报告查看的完整路径。

其次，本文关注测评解释的可追溯性。系统在 ATMR 主线中引入 RAG 知识检索，将报告生成和多智能体辩论建立在知识库证据基础上，避免报告只依赖大模型自由生成。对于异常作答，系统记录作答时间、选项合法性和风险提示，使报告能够说明哪些结论更稳定，哪些结论需要谨慎解释。该设计有助于提高测评报告的透明度，也为后续人机协同咨询提供了上下文。

再次，本文探索了问卷证据与行为信号并列呈现的系统设计。ATMR 问卷主线反映用户自陈数据，多模态 Big Five 辅线反映视频外显行为线索。二者标签体系不同，不能直接做数值相加或强制映射。本文将大五人格报告设计为独立报告，并允许在聊天咨询中与 ATMR 报告同时关联，从而保留两类证据的边界。这种设计比简单融合更稳妥，也更符合当前系统的真实成熟度。

最后，本文具有一定的复现与工程整合价值。多模态人格预测论文通常依赖较重的预处理、特征提取和训练环境，难以直接嵌入在线业务系统。本文采用“离线复现层 + 在线接入层”的结构，先在独立目录中完成 CFI-V2 数据预处理、CLIP 与 wav2clip特征提取、feature bundle 构建、AGTN-MTL baseline 训练和评估，再将稳定 checkpoint 通过服务层接回在线系统。这种策略降低了研究性依赖对主系统稳定性的影响。

## 1.3 国内外研究现状

心理测评系统的发展大致经历了纸笔量表、在线量表、智能解释和多源证据分析几个阶段。传统量表强调题目设计和信效度验证，在线量表则进一步强调测评流程管理、报告自动生成和结果归档。近年来，随着大语言模型和检索增强生成技术的发展，测评系统开始尝试把知识库检索、问答式解释和个性化建议加入报告流程。本文的 ATMR 主线正是在这一背景下，将测评作答、智能选题、模块辩论和 RAG 证据组织为统一流程。

在人格预测研究方面，Big Five 是常见的人格特质模型之一[[REF:5]]，包含开放性、尽责性、外向性、宜人性和神经质五个维度。早期自动人格预测方法多依赖手工特征或单模态视觉特征，随后逐渐引入语音、文本和跨模态融合。多模态方法的优势在于能够综合利用人的表情、姿态、说话内容、声音节奏和场景信息，但难点在于不同模态的时间尺度、噪声来源和表示空间存在差异。

CLIP 通过自然语言监督学习视觉表示[[REF:2]]，为图像与文本之间建立了共享语义空间；Wav2CLIP 则进一步从 CLIP 中蒸馏音频表征能力[[REF:3]]，使音频和视觉语义之间能够形成可比较的嵌入。这类预训练模型为小样本人格预测任务提供了较稳定的特征基础。本文多模态子系统使用 CLIP 提取视觉和文本特征，使用 wav2clip 提取音频特征，并通过统一 feature bundle契约组织模型输入。

Transformer 及其注意力机制[[REF:4]]在序列建模和多模态任务中得到广泛应用。对于视频人格预测而言，人格线索往往不是某一帧或某一个词单独决定的，而是在多个时间片段中逐渐表现出来。因此，仅使用平均池化或简单拼接会丢失部分时序关系。参考论文中的自适应图 Transformer 将图结构与注意力机制结合，用于建模视频帧和音频 patch 之间的关系[[REF:1]]。本文实现的 AGTN-MTL baseline 采用图卷积块、位置编码、时间注意力和残差通道注意力融合，形成适合当前工程环境的可训练版本。

综合来看，已有研究为本文提供了三方面启发：其一，问卷系统需要强调流程可靠性和解释透明度；其二，多模态人格预测需要在特征提取、时序建模和融合策略之间取得平衡；其三，研究型模型接入在线系统时应注意边界隔离和失败回退。本文工作并不声称完全解决心理测评的所有问题，而是围绕“可运行、可解释、可扩展”的目标，在工程系统中完成一次较完整的综合实现。

## 1.4 本文主要工作

本文围绕智能心理测评系统完成以下工作。第一，设计并实现 ATMR 在线测评主系统，支持用户注册登录、测评草稿、断点续答、阶段提交、历史记录、报告详情和 AI 咨询。系统后端采用 FastAPI，前端采用 Vue 3，数据层支持本地 SQLite 开发模式和PostgreSQL 部署模式。

第二，设计自适应选题与异常作答检测机制。自适应选题部分基于用户已答题目向量、贝叶斯能力估计、Fisher 信息量、覆盖度、难度匹配和区分度计算候选题推荐分数；异常作答检测部分对明显过快作答等情况进行识别，并将风险信息作为后续解释的参考。

第三，构建多智能体辩论与 RAG 辅助报告生成流程。系统将阶段性评分和模块结论组织为辩论上下文，由不同角色的分析代理从积极潜力、风险控制和综合裁判角度生成结构化意见，并调用 PageIndex 知识库检索相关证据，以增强报告解释的依据性。

第四，完成视频多模态人格预测子系统的工程化 baseline。本文围绕 CFI-V2 数据集建立 manifest、视频抽帧、音频提取、Whisper 转写、CLIP 视觉/文本特征、wav2clip 音频特征、feature bundle、AGTN-MTL baseline 训练、评估和推理链路，并将当前最优 checkpoint 接入在线服务。

第五，完成大五人格报告与主系统的并列接入。系统在历史页中区分 ATMR 测评报告和大五人格视频报告，在报告页展示雷达图、五维分数、维度简析和 AI 解读，并允许聊天会话同时关联 ATMR 报告和大五人格报告，为后续咨询提供双证据上下文。

## 1.5 论文结构安排

本文共分为五章。第一章介绍课题背景、研究意义、相关研究现状、本文主要工作和论文结构。第二章阐述 ATMR 测评、Big Five人格模型、RAG、预训练多模态特征、图结构时序建模和系统开发技术基础。第三章分析系统需求，并给出总体架构、数据流、功能模块和数据库设计思路。第四章介绍关键模块的设计与实现，包括自适应选题、异常作答检测、多智能体辩论、RAG 检索、多模态特征链路、AGTN-MTL baseline 以及前端报告体验。第五章对系统测试、实验结果、工程边界和后续工作进行总结。
