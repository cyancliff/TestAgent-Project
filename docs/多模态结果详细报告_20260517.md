当前多模态部分已经从“离线研究脚本”推进到“可训练、可评估、可在线推理、可生成报告、可进入聊天上下文”的工程化阶段。视频 Big Five 子系统已经并入主系统，能够从用户上传视频中提取视觉、音频和文本线索，调用真实 checkpoint 输出五维人格分数，并保存为独立的大五人格报告。

微表情部分已经完成 MOL 方法的本地部署、Windows 兼容处理、公开 TIM20 序列数据 quick baseline、批量特征提取、微表情摘要服务、报告/聊天上下文接入和有无微表情特征的训练入口。合并后，微表情作为“细粒度非语言视觉线索增强模块”进入主仓库，但它仍应定位为辅助模态，不应被写成独立人格判断依据。

当前最稳妥的论文表述是：

> 本文完成了视频多模态人格预测方法的工程化 baseline 复现与系统接入，并进一步接入 MOL 微表情识别模块作为辅助视觉线索。多模态结果用于补充 ATMR 问卷测评证据链，而不是替代问卷或临床评估。

## 3. 数据与实验设置

### 3.1 视频人格预测数据

视频人格预测围绕 `CFI-V2` 数据集展开，保持训练、验证、测试划分：

| 划分 | 样本数 |
| --- | ---: |
| train | 6000 |
| val | 2000 |
| test | 2000 |

模型输出为 Big Five 五维连续分数：

1. `openness`
2. `conscientiousness`
3. `extraversion`
4. `agreeableness`
5. `neuroticism`

评价指标包括：

| 指标 | 含义 |
| --- | --- |
| MSE | 均方误差，越低越好 |
| RMSE | 均方根误差，越低越好 |
| MAE | 平均绝对误差，越低越好 |
| ACC | 按人格回归任务常用口径 `1 - MAE` 计算，越高越好 |
| PCC | Pearson 相关系数，反映预测与标签变化趋势的一致性 |
| CCC | Concordance 相关系数，同时考虑相关性和数值一致性 |
| R² | 相对标签均值基线的解释能力 |

### 3.2 微表情数据

微表情 baseline 使用公开 Hugging Face 数据集 `GriErik123/Micro-Expression-Recognition` 中的 TIM20 图像序列，并转换为 MOL 可读取的 SAMM/CASME2/SMIC 风格目录：

```text
third_party/MOL/data/SAMM_data_3/
third_party/MOL/data/CASME2_data_3/
third_party/MOL/data/SMIC_data_3/
```

重要边界：

1. 官方 SAMM、CASME2、SMIC 原始数据通常需要申请授权。
2. 当前本机没有官方授权原始数据。
3. 当前结果是公开 TIM20 序列数据上的本地 quick baseline，用于验证代码、数据转换、LOSO 风格训练评估和系统接入链路。
4. 因此不能表述为“完全复现 MOL 官方结果”。

## 4. 视频 Big Five 实验结果

### 4.1 全量 baseline 与调参结果

| 实验 | 测试样本数 | MSE | MAE | ACC | PCC | CCC | R² | 说明 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 初始全量 baseline | 2000 | 0.0199 | 0.1136 | 0.8864 | 0.3422 | 0.1925 | 0.1154 | 首轮全量训练结果 |
| `lr1e-4 / dropout 0.2` | 2000 | 0.0115 | 0.0861 | 0.9139 | 0.7062 | 0.6327 | 0.4881 | 当前在线默认 checkpoint |
| `lr1e-4 / dropout 0.3` | 2000 | 0.0122 | 0.0885 | 0.9115 | 0.7062 | 0.5776 | 0.4609 | 调参对照 |
| `lr2e-4 / dropout 0.3` | 2000 | 0.0131 | 0.0916 | 0.9084 | 0.6684 | 0.5410 | 0.4196 | 调参对照 |

当前最优版本为 `lr1e-4 / dropout 0.2`。相对初始全量 baseline，它在 MAE、PCC、CCC 和 R² 上均有明显提升：

| 指标 | 初始 baseline | 最优版本 | 变化 |
| --- | ---: | ---: | ---: |
| MSE | 0.0199 | 0.0115 | 降低约 42.0% |
| MAE | 0.1136 | 0.0861 | 降低约 24.2% |
| ACC | 0.8864 | 0.9139 | 提升约 0.0275 |
| PCC | 0.3422 | 0.7062 | 提升约 0.3640 |
| CCC | 0.1925 | 0.6327 | 提升约 0.4402 |
| R² | 0.1154 | 0.4881 | 提升约 0.3727 |

解释：

1. MAE 降低说明预测分数的平均误差减小。
2. PCC 提升说明模型已经能较好捕捉人格分数变化趋势。
3. CCC 提升说明预测不只是相关性更好，数值一致性也有改善。
4. R² 接近 0.49，说明相对标签均值基线已经具备一定解释能力。

### 4.2 与参考论文结果的关系

参考论文在 CFI-V2 上报告的代表性指标为：

| 来源 | ACC | PCC | CCC | R² |
| --- | ---: | ---: | ---: | ---: |
| 参考论文 CFI-V2 | 0.9196 | 0.7267 | 0.7085 | 0.5226 |
| 当前最优工程 baseline | 0.9139 | 0.7062 | 0.6327 | 0.4881 |

当前工程 baseline 的 ACC 和 PCC 已接近参考论文报告值，但 CCC 和 R² 仍有差距。这说明当前结果已经具备论文汇报价值，但表达上仍应保持谨慎：

1. 可以说“完成了参考论文路线的工程化 baseline 复现和系统接入”。
2. 可以说“当前最优版本在 ACC/PCC 上接近参考论文代表性结果”。
3. 不应说“完整复现了原论文所有结构、损失函数和最终性能”。

差距的可能原因：

1. 当前 baseline 尚未完整复现论文中的所有多任务损失。
2. `scene-description association feature` 使用的是工程版 `bg_features`，不是完全等同原论文实现。
3. 当前调参规模和重复实验次数有限。
4. 数据预处理、特征抽取和训练细节可能与原论文存在差异。

## 5. bg_features 对照结果

`bg_features` 是场景语义辅助特征，工程实现为 256 维特征，结合 CLIP 画面特征、文本特征、音频特征和转写统计构建。它的目标是补充“场景-描述”层面的弱语义线索，而不是替代视觉、音频或文本主模态。

| 实验 | 测试样本数 | MSE | MAE | ACC | PCC | CCC | R² |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 三模态 baseline | 2000 | 0.011543 | 0.086074 | 0.913926 | 0.706168 | 0.632742 | 0.488076 |
| 三模态 + `bg_features` | 2000 | 0.011506 | 0.086201 | 0.913799 | 0.707187 | 0.632360 | 0.489706 |

相对变化：

| 指标 | 变化 |
| --- | ---: |
| MSE | -0.000037 |
| MAE | +0.000127 |
| ACC | -0.000127 |
| PCC | +0.001019 |
| CCC | -0.000382 |
| R² | +0.001630 |

结论：

1. `bg_features` 在 MSE、PCC、R² 上有轻微改善。
2. MAE、ACC、CCC 基本持平，未形成显著性能突破。
3. 论文中适合将其表述为“场景语义辅助特征带来有限但正向的补充信息”。
4. 不适合将其写成主要创新点或决定性提升来源。

## 6. 单模态与多模态消融结果

| 变体 | MSE | MAE | ACC | PCC | CCC | R² |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 文本单模态 | 0.0196 | 0.1119 | 0.8881 | 0.3644 | 0.2417 | 0.1304 |
| 视觉单模态 | 0.0115 | 0.0861 | 0.9139 | 0.6988 | 0.6611 | 0.4880 |
| 音频单模态 | 0.0174 | 0.1065 | 0.8935 | 0.4965 | 0.3548 | 0.2270 |
| 三模态 | 0.0115 | 0.0861 | 0.9139 | 0.7062 | 0.6327 | 0.4881 |
| 三模态 + `bg_features` | 0.0115 | 0.0862 | 0.9138 | 0.7072 | 0.6324 | 0.4897 |

消融结论：

1. 视觉单模态贡献最大，几乎接近三模态 baseline。
2. 音频单模态弱于视觉，但明显优于文本单模态，说明语音和音色/韵律相关信息仍有补充价值。
3. 文本单模态相对较弱，可能受转写质量、文本长度、访谈内容差异等因素影响。
4. 三模态在 PCC 上优于单一视觉模态，说明融合有助于相关性指标稳定。
5. `bg_features` 对整体结果影响有限，适合作为辅助线索而不是主性能来源。

论文写作建议：

> 消融实验显示，当前 CFI-V2 设置下视觉模态对 Big Five 预测贡献最明显，音频模态提供次级补充信息，文本模态单独预测能力较弱。多模态融合在相关性指标上更稳定，说明跨模态信息具有一定互补性。

## 8. MOL 微表情 baseline 结果

### 8.1 方法选择

微表情部分选择 MOL 作为 baseline。MOL 的核心特点是联合建模：

1. 微表情分类；
2. 光流运动信息；
3. 人脸关键点结构。

相比只做单纯表情分类，MOL 更适合作为视频多模态系统中的细粒度面部运动线索来源。

## 10. 报告与聊天上下文接入

合并后，大五人格报告解读 prompt 同时接入以下信息：

1. Big Five 五维分数；
2. 维度排序；
3. 模态质量摘要；
4. 预测置信度摘要；
5. 与 ATMR 的辅助一致性摘要；
6. 微表情短时面部线索；
7. Big Five RAG 知识库证据；
8. 使用边界。

微表情在用户报告中的建议表达：

> 微表情结果仅作为短时面部运动线索，可辅助理解视频片段中的状态表达，不代表稳定人格标签，也不应作为单一判断依据。

这种表达可以避免把微表情过度解释为“真实情绪”或“人格定论”。

## 12. 论文写作建议

### 12.1 可强调的内容

1. 系统已经形成 ATMR 问卷主线和视频多模态辅线并列的双证据链结构。
2. 视频 Big Five 子系统已完成离线训练、调参、在线真实推理和报告接入。
3. 当前最优工程 baseline 在 CFI-V2 测试集上取得 `MAE=0.0861`、`ACC=0.9139`、`PCC=0.7062`、`CCC=0.6327`、`R²=0.4881`。
4. `bg_features` 带来有限但正向的辅助信息，可作为场景语义补充特征。
5. MOL 微表情模块已完成本地部署、quick baseline 和系统接入，为后续细粒度视觉线索消融提供条件。

### 12.2 必须谨慎的内容

1. 不要宣称完整复现参考论文全部方法和指标。
2. 不要宣称微表情能够直接判断人格。
3. 不要把 TIM20 quick baseline 写成官方 SAMM/CASME2/SMIC 授权数据严格复现。
4. 不要把 `bg_features` 写成显著性能突破。
5. 不要把多源证据并列解释写成已经经过大规模真实用户验证的强融合模型。

### 12.3 推荐表述

可用于组会或论文中的表述：

> 本文在 ATMR 问卷测评主线之外，构建了视频多模态 Big Five 人格预测子系统，并完成从视频预处理、视觉/音频/文本特征提取、AGTN-MTL baseline 训练评估到在线报告生成的完整工程闭环。实验结果显示，当前最优 checkpoint 在 CFI-V2 测试集上取得 `MAE=0.0861`、`ACC=0.9139`、`PCC=0.7062`，说明视频多模态结果能够作为问卷测评之外的辅助人格线索。

> 在此基础上，本文进一步接入 MOL 微表情识别模块，将短时面部运动线索以结构化 `micro_expression_feature.json` 的形式写入多模态产物，并提供批量提取、报告摘要和消融训练入口。当前 MOL 实验基于公开 TIM20 序列数据完成 quick baseline，主要用于验证方法链路和系统接入，后续可在官方授权数据上继续进行严格复现和正式消融。

## 13. 下一步建议

### 13.1 工程侧

1. 在 `main` 上持续跑完整测试，确保合并后的微表情代码不破坏现有 ATMR 和大五报告能力。
2. 将 MOL 依赖环境说明进一步收敛为独立安装文档，避免主系统部署误装重依赖。

5. 如果官方 SAMM/CASME2/SMIC 授权数据到位，再补充严格复现实验。

2. 将 MOL 写成“细粒度非语言视觉线索增强模块”。
3. 在实验章节分清“正式 CFI-V2 Big Five 结果”和“微表情 quick baseline / smoke 结果”。
4. 在结论章节强调系统边界：多模态与微表情不替代问卷、访谈或临床评估。

## 14. 最终阶段性判断

当前多模态部分已经具备三类可汇报成果：

1. **真实可运行**：视频大五人格已能在线完成真实推理并生成报告。
