# ATMR 多源证据可靠性指标方案

## 1. 设计目标

当前系统中，ATMR 问卷测评是主线，多模态 Big Five 和微表情分析是辅助线。由于三者并不共享同一套标签体系，也缺少同一批用户的真实人格标注，因此不宜直接表述为“多模态和微表情提高了 ATMR 测评准确率”。

更合理的量化目标是：

> 在不改变 ATMR 主评分的前提下，量化多模态 Big Five 与微表情线索是否增强了 ATMR 报告的证据支持，或者提示报告需要谨慎解释。

因此，本文将多模态和微表情定位为 ATMR 主测评之外的辅助证据链，用于衡量报告解释可靠性、跨来源一致性和短时状态风险。

## 2. 主指标：AERI

本文提出 ATMR 多源证据可靠性指数：

```text
AERI = ATMR Evidence Reliability Index
```

该指标用于衡量一份 ATMR 报告在结合辅助证据后的整体解释可靠性。

定义如下：

```text
AERI = clamp(A + 0.25 × E_bf + 0.10 × E_micro, 0, 1)
```

其中：

```text
A = ATMR 原始可信度
E_bf = Big Five 跨证据支持项
E_micro = 微表情状态支持项
```

`clamp(x, 0, 1)` 表示将最终结果限制在 `[0, 1]` 范围内。

## 3. 辅助证据增益：MEG

为了量化多模态和微表情相对于原始 ATMR 的增益，定义多源证据增益指数：

```text
MEG = AERI - A
```

解释规则：

| MEG 范围 | 含义 | 报告策略 |
|---:|---|---|
| MEG >= 0.05 | 辅助证据有效增强 ATMR 解释可信度 | 可以增强报告解释力度 |
| -0.05 < MEG < 0.05 | 辅助证据基本中性 | 保持原始解释强度 |
| MEG <= -0.05 | 辅助证据与 ATMR 存在张力 | 降低解释强度，提示谨慎使用 |

该指标不改变用户的 ATMR 原始得分，只改变系统对报告解释强度的判断。

## 4. ATMR 原始可信度 A

`A` 使用系统已有的 ATMR 可信度字段：

```text
A = trust_summary.assessment_confidence
```

该值由答题行为风险、异常作答数量、题级可信度和维度完成度共同计算。

含义：

| A 范围 | 含义 |
|---:|---|
| A >= 0.80 | ATMR 作答质量较高，主报告可以正常解释 |
| 0.60 <= A < 0.80 | ATMR 作答质量中等，报告适合倾向性参考 |
| A < 0.60 | ATMR 作答质量偏低，报告需要谨慎解释 |

## 5. Big Five 跨证据支持项 E_bf

Big Five 多模态结果不直接替代 ATMR，而是用于判断视频人格线索是否支持 ATMR 结论。

使用三个系统已有字段：

```text
C = consistency_summary.overall_score
Q = quality_summary.overall_quality
P = confidence_summary.overall_confidence
```

其中：

| 符号 | 含义 |
|---|---|
| C | ATMR 与 Big Five 的跨证据一致性 |
| Q | 多模态输入质量 |
| P | Big Five 预测置信度 |

Big Five 支持项定义为：

```text
E_bf = Q × P × (2C - 1)
```

设计含义：

| 条件 | 结果 |
|---|---|
| C > 0.5 | Big Five 倾向于支持 ATMR |
| C = 0.5 | Big Five 对 ATMR 基本中性 |
| C < 0.5 | Big Five 与 ATMR 存在张力 |
| Q 或 P 较低 | 多模态证据影响自动减弱 |

这样可以避免低质量视频或低置信预测对 ATMR 报告产生过强影响。

## 6. 微表情状态支持项 E_micro

微表情不能直接作为稳定人格标签。本文只将其作为短时面部状态线索，用于判断当前视频状态是否适合强解释。

设 MOL 微表情模块输出：

```text
negative = 负向概率
surprise = 惊讶概率
positive = 正向概率
conf = 主导微表情置信度
```

先计算短时状态风险：

```text
micro_risk = conf × (0.7 × negative + 0.3 × surprise) × (1 - 0.5 × positive)
```

再计算状态稳定度：

```text
micro_stability = 1 - micro_risk
```

最后定义微表情支持项：

```text
E_micro = conf × (2 × micro_stability - 1)
```

解释规则：

| E_micro 范围 | 含义 |
|---:|---|
| E_micro > 0 | 当前面部状态相对稳定，可轻微支持报告解释 |
| E_micro = 0 | 微表情线索中性 |
| E_micro < 0 | 短时负向或惊讶状态较强，报告应谨慎解释 |

微表情在 AERI 中的权重设置为 `0.10`，因为它反映的是短时状态，不应过度影响 ATMR 主测评结论。

## 7. AERI 分级规则

| AERI 范围 | 等级 | 报告解释策略 |
|---:|---|---|
| AERI >= 0.80 | 强证据支持 | 可以正常解释 ATMR 主画像 |
| 0.60 <= AERI < 0.80 | 中等证据支持 | 需要保留边界说明 |
| AERI < 0.60 | 证据不足或存在张力 | 建议谨慎解释、复测或结合更多证据 |

## 8. 实验分组设计

为了证明多模态和微表情对 ATMR 报告有辅助价值，可以设计三组对照实验。

| 组别 | 使用信息 | 计算方式 | 目的 |
|---|---|---|---|
| ATMR-only | 只使用 ATMR 可信度 | `A` | 原始基线 |
| ATMR + Big Five | 加入多模态一致性 | `clamp(A + 0.25 × E_bf, 0, 1)` | 验证视频 Big Five 是否提供跨证据支持 |
| ATMR + Big Five + Micro | 加入微表情状态线索 | `AERI` | 验证完整辅助证据链是否改善解释可靠性判断 |

## 9. 评价指标

建议在实验中统计以下指标：

| 指标 | 计算方式 | 含义 |
|---|---|---|
| 平均 AERI | 所有样本 AERI 的均值 | 报告整体解释可靠性 |
| 平均 MEG | 所有样本 MEG 的均值 | 辅助证据平均增益 |
| 增强样本比例 | `MEG >= 0.05` 的样本占比 | 多模态/微表情有效支持的比例 |
| 张力样本比例 | `MEG <= -0.05` 的样本占比 | 跨来源冲突或谨慎解释样本比例 |
| 低可信识别率 | 低 AERI 样本中异常或冲突样本占比 | 系统识别风险报告的能力 |
| 过度自信下降率 | ATMR-only 高可信但 AERI 降级的比例 | 辅助证据降低过度解释的能力 |

重点证明：

```text
加入多模态和微表情后，系统能更好地区分哪些 ATMR 报告可以强解释，哪些报告需要谨慎解释。
```

而不是证明：

```text
多模态和微表情一定提高 ATMR 分数准确率。
```

## 10. 示例计算

假设某用户结果如下：

```text
A = 0.78
C = 0.72
Q = 0.85
P = 0.80
negative = 0.30
surprise = 0.20
positive = 0.40
conf = 0.60
```

Big Five 支持项：

```text
E_bf = Q × P × (2C - 1)
     = 0.85 × 0.80 × (2 × 0.72 - 1)
     = 0.85 × 0.80 × 0.44
     = 0.2992
```

微表情风险：

```text
micro_risk = 0.60 × (0.7 × 0.30 + 0.3 × 0.20) × (1 - 0.5 × 0.40)
           = 0.60 × 0.27 × 0.80
           = 0.1296
```

微表情稳定度：

```text
micro_stability = 1 - 0.1296 = 0.8704
```

微表情支持项：

```text
E_micro = 0.60 × (2 × 0.8704 - 1)
        = 0.60 × 0.7408
        = 0.4445
```

最终 AERI：

```text
AERI = clamp(0.78 + 0.25 × 0.2992 + 0.10 × 0.4445, 0, 1)
     = clamp(0.78 + 0.0748 + 0.0445, 0, 1)
     = 0.8993
```

辅助证据增益：

```text
MEG = AERI - A
    = 0.8993 - 0.78
    = 0.1193
```

解释：

```text
MEG = +0.1193，说明多模态和微表情辅助证据对 ATMR 报告形成了正向支持，报告解释可靠性从中等偏高提升到强证据支持。
```

|---|---:|---:|---:|---:|---:|---:|---:|---|
| case-1 | 0.82 | 0.76 | 0.88 | 0.80 | 0.79 | 0.94 | +0.12 | 辅助增强 |
| case-2 | 0.78 | 0.42 | 0.85 | 0.75 | 0.61 | 0.66 | -0.12 | 存在张力 |
| case-3 | 0.55 | 0.70 | 0.60 | 0.58 | 0.80 | 0.63 | +0.08 | 中等增强 |

## 12. 论文表述建议

可以写为：

> 本文提出 ATMR 多源证据可靠性指数 AERI，用于量化多模态人格预测和微表情线索对 ATMR 主测评结果的辅助价值。AERI 不改变 ATMR 原始得分，而是综合 ATMR 作答可信度、ATMR-Big Five 一致性、多模态输入质量、预测置信度和微表情状态稳定度，对报告解释强度进行量化调节。当 MEG 为正时，说明外部证据对 ATMR 结论形成支持；当 MEG 为负时，说明跨来源证据存在张力，系统应降低解释强度并提示谨慎使用。

还可以补充：

> 由于微表情反映的是短时面部状态，而非稳定人格特质，本文仅将其作为报告解释边界的辅助变量。该设计避免了将短时情绪误判为长期人格倾向，同时保留其在识别紧张、负向或不稳定状态方面的参考价值。

## 13. 方法边界

该指标只能证明：

```text
多模态和微表情可以增强 ATMR 报告的证据链完整性、解释可靠性和风险提示能力。
```

不能直接证明：

```text
多模态和微表情提高了 ATMR 量表本身的心理测量学效度。
```

因此，论文中应避免使用“显著提高 ATMR 准确率”之类表述，更适合使用：

```text
增强报告解释可靠性
提供跨来源辅助证据
降低过度解释风险
提升测评结果的证据链完整度
```
