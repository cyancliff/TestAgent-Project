# 管理端质量治理后台说明

更新时间：2026-05-02

## 1. 定位

管理端定位为：

> 面向 ATMR 质量治理的轻量后台。

它不是系统主创新点，而是为 ATMR-CAT、异常作答检测、可信度模型、证据链和实验结果提供工程化管理支撑。

用户端继续负责：

- ATMR 测评作答
- ATMR 报告查看
- 大五人格视频报告
- AI 咨询

管理端负责：

- 题库质量维护
- 测评可信度监控
- 异常作答统计
- 用户报告查看
- 实验结果展示

## 2. 权限设计

系统新增用户角色：

```text
user / admin
```

默认管理员用户名由环境变量控制：

```text
ADMIN_USERNAMES=admin
```

命中该配置的用户会自动标记为 `admin`。管理接口统一使用后端权限校验，普通用户访问 `/api/v1/admin/*` 会返回 `403`。

登录响应和 `/auth/me` 会返回：

```text
role
is_admin
```

前端根据该字段显示或隐藏管理端入口。

## 3. 第一版功能

### 管理首页

展示：

- 用户数
- ATMR 测评数
- 已完成报告数
- 平均整体可信度
- 异常作答比例
- 低可信报告数
- 大五报告数量
- 当前模型版本摘要

### 题库质量

支持：

- 按维度、关键词、启用状态筛选题目
- 查看题目难度、区分度、平均作答时间、异常率
- 修改轻量题库参数：
  - `trait_label`
  - `difficulty`
  - `discrimination`
  - `avg_time`
  - `is_reverse`
  - `is_active`

第一版不开放题干、选项和分值结构编辑，避免破坏量表一致性。

### 报告质量

支持：

- 查看 ATMR 报告列表
- 查看完整 ATMR 报告和答题证据
- 查看大五人格报告列表
- 查看完整大五报告、质量摘要、置信度和一致性分析

### 实验结果

管理端只读取本地已有实验产物，不触发训练或重训任务。

当前展示：

- ATMR-CAT 默认实验
- ATMR-CAT 多随机种子实验
- ATMR-CAT 异常注入实验
- 可信度加权稳健性实验
- `bg_features` 重训结果
- 多模态消融实验

## 4. 项目说明

推荐在系统设计说明中使用：

> 系统采用用户端与管理端分离的权限设计。用户端面向测评作答、报告查看和咨询交互；管理端面向题库维护、测评质量监控、异常作答统计、实验结果管理和模型版本查看。该设计增强了系统的可维护性与可扩展性，并为 ATMR-CAT 题库参数校准、作答质量控制和多模态辅助证据链评估提供管理支撑。

演示时可以这样讲：

> 管理端不是为了扩大功能堆叠，而是为了支撑 ATMR 原创机制落地。ATMR-CAT 依赖题库参数，可信度模型依赖异常统计，实验结果也需要集中展示，因此我做了一个轻量质量治理后台，用来管理这些核心创新的运行证据。

## 5. 边界

- 管理端第一版允许管理员查看完整用户报告。
- 不提供用户删除、报告删除等高风险操作。
- 不在管理端触发多模态训练或长任务。
- 题库轻管理只修改参数和启用状态，不直接改题干、选项和分值结构。
- 如果后续真实上线，需要进一步增加操作审计和更细粒度的数据脱敏。
