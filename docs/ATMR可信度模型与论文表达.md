# ATMR 可信度模型与论文表达

更新时间：2026-05-01

## 1. 模型定位

本文将 ATMR 可信度模型定义为：

> 基于无感知行为风险评估的 ATMR 测评可信度模型。

该模型分为三层：

1. **单题可信度**：判断某一道题的作答证据是否可靠。
2. **维度可信度**：判断 A/T/M/R 某个维度的结论是否可靠。
3. **整体可信度**：判断本次测评报告整体是否适合强解释。

核心思想是：

> 系统不直接删除异常答案，而是将作答行为风险转化为题级可信度，并进一步聚合为维度级与整体级可信度，从而实现测评结果的可解释降权。

## 2. 单题可信度

每道题先由后台行为风险模型得到风险分：

```text
r_i ∈ [0, 100]
```

其中，`r_i` 表示第 `i` 题的风险分，来自作答时间、首次交互延迟、鼠标行为摘要、选项变更、页面切出、连续同选项、极端选项集中等规则。

若：

```text
r_i >= 50
```

则该题标记为异常：

```text
z_i = 1
```

否则：

```text
z_i = 0
```

单题可信度定义为：

```text
c_i = clamp(1 - 0.0065 * r_i - 0.08 * z_i, 0.2, 1.0)
```

含义：

- `r_i` 越高，可信度越低。
- 若题目被标记异常，额外降低 `0.08`。
- 下限设为 `0.2`，表示异常答案不直接删除，只作为低可信证据保留。
- 上限设为 `1.0`，表示正常答案最高可信。

论文表达建议：

> 对第 `i` 道题，系统根据后台行为风险模型得到风险分 `r_i`。为避免异常作答被简单剔除导致证据缺失，本文将风险分映射为题级可信度 `c_i`。当题目被标记为异常时，额外引入异常惩罚项，使该题在后续维度画像和报告解释中被降权。

## 3. 维度可信度

对 ATMR 的每个维度：

```text
m ∈ {A, T, M, R}
```

收集该维度下所有作答题目：

```text
S_m = {i | item_i belongs to dimension m}
```

维度基础可信度为该维度题目可信度均值：

```text
mean_c_m = mean(c_i), i ∈ S_m
```

考虑维度完成度：

```text
completion_m = min(n_m / N_m, 1)
```

其中：

- `n_m` 是该维度实际答题数量。
- `N_m` 是该维度期望题量，当前为 10。

维度异常数量：

```text
a_m = sum(z_i), i ∈ S_m
```

维度可信度定义为：

```text
C_m = clamp(mean_c_m * (0.85 + 0.15 * completion_m) - 0.015 * a_m, 0, 1)
```

含义：

- 维度内题目平均可信度越高，维度可信度越高。
- 题量越完整，可信度越充分。
- 异常题越多，该维度额外降权。
- 这能解释“某个维度分数高，但可信度不一定高”。

标签划分：

```text
C_m >= 0.80：较高
0.60 <= C_m < 0.80：中等
C_m < 0.60：较低
```

论文表达建议：

> 维度可信度用于衡量某一 ATMR 维度画像的证据稳定性。本文不仅考虑该维度内题目的平均可信度，还引入维度完成度和异常题数量作为修正项。这样可以避免少量高风险答案对维度结论产生过强影响，并为报告中的“谨慎解释”提供量化依据。

## 4. 整体测评可信度

整体可信度基于所有题目的单题可信度均值：

```text
mean_c = mean(c_i), i ∈ all answers
```

总异常题数量：

```text
A = sum(z_i)
```

整体可信度定义为：

```text
C = clamp(mean_c - min(0.01 * A, 0.12), 0, 1)
```

含义：

- 整体作答越稳定，报告整体可信度越高。
- 异常题越多，整体报告额外降权。
- 总异常惩罚最多为 `0.12`，避免极端情况下把报告完全否定。

标签划分：

```text
C >= 0.80：较高
0.60 <= C < 0.80：中等
C < 0.60：较低
```

论文表达建议：

> 整体测评可信度用于衡量本次 ATMR 测评报告的整体参考价值。本文采用题级可信度均值作为基础，并根据异常作答总量进行全局惩罚。该设计使系统能够在保留完整作答证据的同时，对低质量作答造成的报告不确定性进行显式表达。

## 5. 可信度加权参考分

为避免作答行为特征直接改写用户画像，系统不使用可信度加权分替代原始 ATMR 得分。

主报告仍然使用：

```text
total_score / percentage / level
```

作为维度主结论。可信度加权结果只作为稳健性参考字段：

```text
confidence_weighted_raw_score
confidence_weighted_score
confidence_weighted_percentage
confidence_weighted_delta
```

其作用是观察低可信答案被降权后，维度得分是否与主得分存在明显差异。若差异较小，说明该维度解释较稳定；若差异较大，说明异常或低可信作答可能影响该维度解释强度。

论文表达建议：

> 考虑到作答行为特征可能受到设备、操作习惯和环境干扰影响，本文不直接使用可信度加权结果替代原始 ATMR 得分，而是保留原始得分作为主画像结果，并将可信度加权结果作为稳健性参考。可信度模型的主要作用是控制报告解释强度，并在异常作答干扰实验中验证其对低质量作答的抑制能力。

详细实验设计见：

```text
docs/ATMR可信度加权稳健性实验说明.md
```

## 6. 报告中的三层解释

### 单题层

展示字段：

```text
题号、选择、得分、风险原因、行为摘要、单题可信度
```

推荐文案：

> 该题被后台行为风险模型标记为异常，因此在证据链中降低权重，但不会直接删除。

### 维度层

展示字段：

```text
维度得分、题目数量、异常数量、维度可信度、解释建议
```

推荐文案：

- 较高：该维度作答稳定，结论可作为主要参考。
- 中等：该维度整体可参考，但需结合异常记录谨慎解释。
- 较低：该维度证据稳定性不足，建议结合复测或其他证据。

### 整体层

展示字段：

```text
整体可信度、异常题数量、平均风险分、报告使用建议
```

推荐文案：

- 较高：本次测评作答质量较高，整体画像可信度较好。
- 中等：本次测评可信度中等，报告结论适合做倾向性参考。
- 较低：本次测评可信度偏低，报告结论需要谨慎使用。

## 7. 论文小节建议

论文中建议单独开一节：

```text
3.x ATMR 测评可信度评估模型
```

建议结构：

1. **问题定义**
   - 传统问卷容易受随意作答、机械作答、低质量作答影响。
   - 直接删除异常答案容易误伤用户，也会破坏测评完整性。

2. **题级可信度建模**
   - 定义 `r_i / z_i / c_i`。
   - 解释风险分到可信度的映射。

3. **维度级可信度聚合**
   - 定义 `C_m`。
   - 解释平均可信度、完成度、异常数量三个因素。

4. **整体测评可信度**
   - 定义 `C`。
   - 解释整体报告如何给出“较高 / 中等 / 较低”。

5. **可信度在报告中的应用**
   - 异常答案不删除，而是降权。
   - 报告展示风险原因和行为摘要。
   - 可信度用于限定解释强度。

推荐总表述：

> 本文提出一种面向 ATMR 测评的分层可信度评估模型。该模型首先根据无感知行为风险评估结果计算题级可信度，再将题级可信度聚合为维度级可信度和整体测评可信度。与直接剔除异常答案不同，本文采用保留证据并降低权重的方式，使系统既能减少低质量作答对画像结果的影响，又能在报告中显式呈现结论的可靠程度。

## 8. 边界说明

- “单体可信度”在本文中统一表述为“单题可信度”。
- 当前不恢复异常追问机制。
- 可信度模型用于测评质量控制，不用于判断用户主观动机。
- 完整鼠标轨迹不入库，只保存压缩行为摘要。
- 论文中不声称该模型证明 ATMR 量表真实心理效度，只声称它增强了作答质量控制与报告解释可信度。
- 可信度加权分只作为稳健性参考，不替代原始 ATMR 主画像、雷达图和等级判断。
