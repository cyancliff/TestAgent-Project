# 毕设开发目标和进度

更新时间：2026-04-30

这份文档不再沿用“主系统未成型”的旧口径。当前项目已经从“搭骨架”进入“实验收口、报告体验打磨和工程治理”阶段。多模态部分已经不再是补接口或跑通链路，而是已经以“大五人格”独立报告形式进入主系统。

## 1. 毕设总体目标

本课题的目标不是做一个简单的问卷网站，而是构建一个由两条证据链共同支撑的智能心理测评系统：

1. 问卷主线：基于 ATMR 四维模型完成答题、评分、ATMR-CAT 自适应选题、无感知异常作答检测、多智能体辩论和可信报告。
2. 多模态辅线：从视频中提取视觉、音频、文本线索，预测 Big Five 人格结果，生成独立的大五人格报告，并作为 ATMR 的辅助证据链增强。

最终希望形成的论文表达是：

- 不只做静态问卷评分
- 不只做大模型生成式报告
- 而是做“问卷 + 行为信号 + 证据检索 + 多模态视频分析”的综合型智能测评系统

## 2. 当前技术路线

### 2.1 在线主系统

当前在线主系统的核心链路为：

```text
用户登录
-> 创建测评草稿
-> intro / fixed / A / T / M / R 阶段答题
-> ATMR-CAT 自适应选题
-> 无感知作答行为风险评估
-> 模块辩论
-> 综合报告
-> 历史记录与 AI 咨询
```

这一条线已经基本闭环，是当前系统演示和毕设主体实现的基础。

### 2.2 多模态子系统

当前多模态采用独立目录和离线流程，技术路线为：

```text
CFI-V2 数据集
-> manifest 构建
-> 视频抽帧 / 音频提取 / Whisper 转写
-> CLIP 视觉与文本特征
-> wav2clip 音频特征
-> feature bundle
-> AGTN-MTL baseline 训练
-> eval / infer
-> 在线真实 checkpoint 推理
-> 大五人格报告 / 历史记录 / AI 咨询上下文
```

这条线当前的工程优先级是：

1. 继续打磨大五人格报告解释质量和演示文案
2. 基于已补齐的论文实验指标整理结果分析
3. 视时间决定是否用新 `bg_features` 重新训练对照模型

### 4.2 已经得到的真实结果

当前已完成两档真实小样本验证：

1. `train 20 / val 5`
   - `mse=0.004983`
   - `mae=0.057872`
2. `train 100 / val 20`
   - `mse=0.016520`
   - `mae=0.100234`

这说明多模态部分已经不再只是“接口脚手架”，而是已经具备真实训练和真实推理能力。

当前也已经完成全量 baseline 与一轮调参，在线默认使用的 checkpoint 为：

- `reports/night_lr1e4_drop02/agtn_mtl_lr1e4_drop02.pt`

该版本测试集结果为：

- `test mse=0.011543`
- `test mae=0.086074`
- `test pcc=0.7062`
- `test ccc=0.6327`
- `test r²=0.4881`

在线真实推理 smoke 已归档到：

- `reports/online_multimodal_smoke_20260425/smoke_result.json`

### 4.3 当前仍不能夸大的地方

- 当前仍应定义为“工程化 baseline + 调参版本”，不是论文原方法的严格完整复现
- 新 `bg_features` 已实现，但当前在线 checkpoint 仍是旧零填充版本，需要重训后才能做正式对照
- 多任务损失、更多随机种子和单模态/多模态消融仍可继续补充
- 大五人格报告已经可演示，但解释模板和失败状态文案仍可继续打磨
