更新时间：2026-04-25

这份文档不再沿用“主系统未成型”的旧口径。当前项目已经从“搭骨架”进入“实验收口和主系统融合”阶段，尤其是多模态部分，重点已经不再是补接口或跑通链路，而是把真实多模态结果接入报告与论文实验。

## 1. 毕设总体目标

本课题的目标不是做一个简单的问卷网站，而是构建一个由两条证据链共同支撑的智能心理测评系统：

1. 问卷主线：基于 ATMR 四维模型完成答题、评分、异常作答检测、多智能体辩论和综合报告。
2. 多模态辅线：从视频中提取视觉、音频、文本线索，预测 Big Five 人格结果，作为补充证据进入报告与后续分析。

最终希望形成的论文表达是：

- 不只做静态问卷评分
- 不只做大模型生成式报告
- 而是做“问卷 + 行为信号 + 证据检索 + 多模态视频分析”的综合型智能测评系统

## 2. 当前技术路线

### 2.1 在线主系统

当前在线主系统的核心链路为：

```text
用户登录
-> 创建测评草稿
-> intro / fixed / A / T / M / R 阶段答题
-> 自适应选题与异常作答检测
-> 模块辩论
-> 综合报告
-> 历史记录与 AI 咨询
```

这一条线已经基本闭环，是当前系统演示和毕设主体实现的基础。

### 2.2 多模态子系统

当前多模态采用独立目录和离线流程，技术路线为：

```text
CFI-V2 数据集
-> manifest 构建
-> 视频抽帧 / 音频提取 / Whisper 转写
-> CLIP 视觉与文本特征
-> wav2clip 音频特征
-> feature bundle
-> AGTN-MTL baseline 训练
-> eval / infer
-> 在线真实 checkpoint 推理
-> 后续接入在线报告
```

这条线当前的工程优先级是：

1. 将多模态任务结果与测评会话建立稳定关联
2. 将 Big Five 视频人格结果展示到报告页和历史记录
3. 补齐论文实验指标与结果分析

2. `train 100 / val 20`
   - `mse=0.016520`
   - `mae=0.100234`

这说明多模态部分已经不再只是“接口脚手架”，而是已经具备真实训练和真实推理能力。

- `test mae=0.086074`

在线真实推理 smoke 已归档到：
