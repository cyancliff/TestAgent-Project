## 2. MOL 微表情 baseline 跑通情况

我们选择了 MOL 作为微表情系统的主要复现方法：

```text
MOL: Joint Estimation of Micro-Expression, Optical Flow, and Landmark via Transformer-Graph-Style Convolution
```

它的优势是同时建模：

- 微表情分类
- 光流运动信息
- 人脸关键点结构

这比单纯微表情分类器更适合接入多模态系统。

### 本机环境

MOL 本地环境已经配好：

```text
Python 3.9
torch==1.13.0+cu117
torchvision==0.14.0+cu117
dlib==19.24.1
opencv-contrib-python-headless==4.7.0.72
numpy==1.23.5
scikit-learn==1.2.2
```

另外已经下载并配置：

```text
utils/shape_predictor_68_face_landmarks.dat
```

这是 Dlib 68 点人脸关键点模型。

### Windows 兼容处理

原 MOL 依赖 `spatial-correlation-sampler`，但这台 Windows 机器没有配置本地 CUDA toolkit，无法编译该扩展。  
因此在 `third_party/MOL/modules/FlowNet.py` 中加入了纯 PyTorch fallback，让 MOL 可以在本机继续运行。

这个 fallback 的特点：

- 输出形状保持一致
- 能跑通训练和推理
- 速度比 CUDA 编译扩展慢

### 数据来源说明

官方 SAMM、CASME2、SMIC 原始数据集通常需要授权申请，本机当前没有这些官方原始数据。  
为了三天内完成组会验收，我们使用公开 Hugging Face TIM20 微表情序列数据包完成本地 baseline 跑通。

数据来源：

```text
GriErik123/Micro-Expression-Recognition
```

注意：这不是论文官方授权原始数据上的严格复现，而是“公开 TIM20 序列数据上的 MOL 本地 baseline”。
