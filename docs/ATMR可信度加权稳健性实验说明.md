# ATMR 可信度加权稳健性实验说明

更新时间：2026-05-01

## 1. 定位

本方案将可信度加权结果定位为：

> ATMR 原始画像结果之外的稳健性参考。

也就是说，系统仍然以原始 ATMR 得分作为主画像结果，报告首页、雷达图、维度等级和主解释文案不被可信度加权结果替代。可信度加权分只用于回答一个更具体的问题：

> 如果某些答案存在较高行为风险，那么降低这些答案的参考权重后，维度得分会不会发生明显变化？

这种处理能避免鼠标移动、页面切出、设备习惯、环境干扰等非心理因素直接改写用户的人格画像，同时保留可信度模型在异常作答质量控制中的价值。

## 2. 接口字段

报告接口 `/assessment/report/{session_id}` 在 `dimension_summary[*]` 中新增以下参考字段：

```text
confidence_weighted_raw_score
confidence_weighted_score
confidence_weighted_percentage
confidence_weighted_delta
```

其中：

- `confidence_weighted_raw_score`：只根据题级可信度重新计算的维度原始参考分。
- `confidence_weighted_score`：在参考原始分基础上叠加原有 ATMR 破局加权奖励后的参考分。
- `confidence_weighted_percentage`：可信度加权参考百分比。
- `confidence_weighted_delta`：可信度加权参考分与主得分的差值。

注意：

- `total_score / percentage / level` 不变，仍然是主结论。
- `weighted_score` 仍然表示原有 ATMR 破局加权分，不与可信度加权混用。
- `confidence_weighted_score` 只作为辅助参考，不参与主雷达图、不参与等级判断。

## 3. 计算方法

对于维度 `m` 下的题目集合 `S_m`，每道题有原始得分 `score_i` 和单题可信度 `c_i`。

若题目没有有效 `answer_confidence`，则默认：

```text
c_i = 1.0
```

可信度加权平均分为：

```text
weighted_avg_m = sum(c_i * score_i) / sum(c_i)
```

可信度加权原始参考分为：

```text
confidence_weighted_raw_score_m = weighted_avg_m * n_m
```

可信度加权参考分为：

```text
confidence_weighted_score_m = clamp(confidence_weighted_raw_score_m + weight_bonus_m)
```

可信度加权差异为：

```text
confidence_weighted_delta_m = confidence_weighted_score_m - total_score_m
```

当 `sum(c_i) = 0` 时，系统回退到原始维度得分，避免极端情况下生成不可解释结果。

## 4. 报告页表达

ATMR 报告页只在维度详情中展示可信度加权参考，不放入主雷达图。

推荐展示文案：

```text
可信度加权参考：xx / 50 分，与主得分差异 ±x.xx。
```

当差异较小时：

```text
与主得分基本一致。
```

当差异较大时：

```text
异常或低可信作答可能影响该维度解释。
```

这种表达的重点不是“系统给用户改分”，而是提示报告解释边界：如果可信度加权参考分与主得分差异较大，说明这个维度的部分结论更适合谨慎解释。

## 5. 鲁棒性实验

新增实验脚本：

```powershell
python scripts/run_atmr_confidence_weighting_experiments.py
```

默认输出目录：

```text
reports/atmr_confidence_weighting_experiments/
```

输出文件：

```text
confidence_weighting_experiment.json
confidence_weighting_experiment.md
summary.md
```

实验流程：

1. 生成模拟用户潜变量。
2. 根据题库参数生成干净作答画像，作为参考目标。
3. 按异常率注入污染作答：`0 / 0.05 / 0.10 / 0.20 / 0.30`。
4. 对污染作答分别计算普通得分和可信度加权参考分。
5. 比较两种结果与干净画像之间的偏差。

主要指标：

- `raw_mae_to_clean`：普通得分相对干净画像的 MAE。
- `weighted_mae_to_clean`：可信度加权参考分相对干净画像的 MAE。
- `improvement`：普通 MAE 减去加权 MAE。
- `normal_drift`：无异常或低异常时，加权参考分相对普通得分的漂移。
- `top1_consistency_raw`：普通得分最高维度是否与干净画像一致。
- `top1_consistency_weighted`：可信度加权后最高维度是否与干净画像一致。
- `assessment_confidence_avg`：平均整体测评可信度。

## 6. 默认实验结果

已运行默认配置：

```powershell
python scripts/run_atmr_confidence_weighting_experiments.py
```

| 0.00 | 0.0000 | 0.0000 | 0.0000 | 0.0000 | 1.0000 | 1.0000 | 1.0000 |
| 0.05 | 0.6677 | 0.4747 | 0.1931 | 0.3304 | 0.9287 | 0.9463 | 0.9554 |
| 0.10 | 1.2429 | 0.8771 | 0.3659 | 0.5925 | 0.9037 | 0.9347 | 0.9104 |
| 0.20 | 2.2333 | 1.5807 | 0.6526 | 0.9722 | 0.8327 | 0.8797 | 0.8182 |
| 0.30 | 3.1218 | 2.2064 | 0.9154 | 1.2566 | 0.7757 | 0.8437 | 0.7403 |

可以写入论文的结论：

- 当异常注入率为 `0` 时，可信度加权参考分与普通得分完全一致，说明该机制不会在正常作答下主动改写主画像。
- 随异常率从 `0.05` 增至 `0.30`，平均整体可信度从 `0.9554` 下降到 `0.7403`，符合“异常越多，解释强度越谨慎”的设计目标。
- 在各异常率下，可信度加权 MAE 均低于普通得分 MAE，说明该机制在模拟异常污染下能降低低质量作答对维度得分的干扰。
- Top-1 一致率也有提升，说明加权参考分对主导维度判断具有一定稳健性帮助，但论文中仍应表述为“辅助参考”，不能写成替代主评分。

## 7. 论文表达

推荐写法：

> 考虑到作答行为特征可能受到设备、操作习惯和环境干扰影响，本文不直接使用可信度加权结果替代原始 ATMR 得分，而是保留原始得分作为主画像结果，并将可信度加权结果作为稳健性参考。可信度模型的主要作用是控制报告解释强度，并在异常作答干扰实验中验证其对低质量作答的抑制能力。

边界说明：

- 该实验验证的是异常干扰下的鲁棒性，不证明 ATMR 量表真实心理效度。
- 如果可信度加权改善明显，可以表述为“降低异常作答对报告解释的干扰”。
- 如果改善不明显，也可以表述为“可信度主要用于解释边界控制”，不强行声称准确性提升。

## 8. 答辩解释

如果老师问“可信度加权会不会影响用户真实作答”，可以这样回答：

> 本系统没有用可信度加权结果替代原始 ATMR 得分。原始得分仍然决定主画像、雷达图和维度等级。可信度加权分只放在维度详情中作为稳健性参考，用来观察低可信答案是否可能影响解释强度。这样既保留用户原始作答结果，又能对异常作答带来的不确定性进行提示。

如果老师问“没有真实大规模数据，实验有什么意义”，可以这样回答：

> 当前实验不是为了证明 ATMR 的真实心理效度，而是构造可控异常干扰环境，比较普通得分和可信度加权参考分在异常污染下相对干净画像的偏差。它证明的是系统质量控制机制的鲁棒性，而不是人格量表本身的效度。
