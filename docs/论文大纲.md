

## 中文摘要

简要说明本课题的研究背景、研究目标、系统方案、关键技术和实验结果。重点概括本文构建的智能心理测评系统：以 ATMR 问卷测评为主线，引入 ATMR-CAT 自适应选题、无感知异常作答检测、可信度降权、多智能体辩论、RAG 知识检索和视频多模态 Big Five 辅助画像，形成“问卷结果 + 行为质量 + 知识证据 + 多模态证据”的综合测评流程。


1. 研究问题：传统问卷测评存在题目固定、作答质量难判断、报告解释单一等问题。

本节可围绕以下内容展开：

1. 在线心理测评系统的发展与应用需求。
2. 自适应测评在减少题量、提高画像效率方面的意义。
3. 异常作答检测与测评可信度表达的必要性。
4. 大模型、RAG 和多智能体方法在报告解释中的辅助价值。
5. 视频多模态人格预测作为问卷测评补充证据链的研究价值。

### 1.2 研究意义

从理论和工程两个角度说明课题意义。

理论意义包括：

1. 探索 ATMR 四维测评与自适应选题机制结合的实现方式。
2. 探索将作答行为风险转化为测评可信度的建模方法。
3. 探索问卷测评结果与多模态人格预测结果并列呈现的综合分析框架。

工程意义包括：

### 4.5 题级、维度级与整体可信度建模

说明可信度模型分为三层：

1. 题级可信度：根据单题风险分和异常标记计算。
2. 维度可信度：结合维度内题目可信度均值、完成度和异常数量计算。

需要强调：系统不直接删除异常答案，而是将其作为低可信证据保留，并在报告解释中进行谨慎提示。

## 第 7 章 实验设计与结果分析

### 7.1 实验目的与评价指标

说明实验分为三类：

1. ATMR-CAT 自适应选题实验。
2. 异常作答与可信度稳健性实验。
3. 视频多模态人格预测实验。

评价指标包括 MAE、后验不确定性、覆盖度、MSE、PCC、CCC、R²、接口成功率、任务完成率等。

### 7.2 ATMR-CAT 冷启动校准实验

介绍模拟用户数、异常注入率、题目参数估计和校准题库结果。可写入已完成的分维度难度、区分度和低质量题统计。

本节结论应保持边界清晰：

1. 校准可以验证自适应选题机制的可行性。
2. 校准不能替代真实用户数据下的信度、效度和题目参数估计。

### 7.3 ATMR-CAT 选题策略对比实验

对比固定选题、随机选题和 ATMR-CAT。根据现有实验结果，可重点分析：

1. 校准后 ATMR-CAT 在每维 4、6、8、10 题设置下均取得较低 MAE。
2. ATMR-CAT 在后验不确定性和题目覆盖度方面表现更稳定。
3. 多随机种子实验表明结果不是单次随机性的偶然现象。

### 7.4 异常注入与可信度鲁棒性实验

分析不同异常注入率下的 MAE、后验不确定性和覆盖度变化。重点说明异常作答会增加画像误差，而 ATMR-CAT 在不同异常率下仍保持相对稳定的选题覆盖和误差表现。

### 7.5 多模态人格预测实验

介绍 CFI-V2 数据集、训练集/验证集/测试集划分、特征类型和模型配置。根据已有结果，可分析：

1. 小样本验证说明多模态链路已经具备真实训练和推理能力。
2. 全量 baseline 和调参版本已经完成测试集评估。
3. bg_features 场景语义辅助特征带来轻微改善，但不应夸大为决定性突破。

### 7.6 单模态与多模态消融实验

对比文本单模态、视觉单模态、音频单模态、三模态和三模态 + bg_features。结合现有实验，可说明当前 CFI-V2 特征设置下视觉分支贡献较强，音频提供补充，文本单模态相对较弱，多模态融合在相关性指标上更稳定。

### 7.7 系统功能与接口测试

介绍用户注册登录、测评流程、报告生成、历史记录、AI 咨询、多模态任务创建和报告查询等功能测试。可补充关键接口测试、异常场景测试和在线 smoke 测试结果。

### 7.8 实验结果讨论

从以下角度讨论实验结果：

1. ATMR-CAT 的优势主要体现在校准后选题稳定性、覆盖度和不确定性降低。
2. 可信度模型增强了报告解释边界，但仍需要真实用户数据进一步验证。
3. 多模态 Big Five 结果适合作为辅助证据链，不宜替代问卷主线。
4. 系统已经形成可运行闭环，但心理测量学效度和真实场景泛化仍需后续研究。

## 第 8 章 总结与展望

### 8.1 论文工作总结

总结本文完成的主要工作：

1. 构建了 ATMR 智能心理测评系统，实现完整在线测评与报告流程。
2. 设计并验证了 ATMR-CAT 自适应选题与冷启动校准机制。
3. 实现了异常作答检测和分层可信度建模。
4. 引入 RAG 和多智能体辩论增强报告解释。
5. 完成视频多模态 Big Five 人格预测子系统的训练、评估和在线接入。
6. 通过多组实验验证系统功能和关键算法效果。

### 8.2 不足之处

客观说明当前工作限制：

1. ATMR 题库参数主要基于模拟用户响应校准，仍缺少大规模真实用户数据验证。
2. 可信度模型参数仍需在真实作答样本中进一步优化。
3. 多模态 baseline 不是参考论文原方法的严格完整复现，多任务损失等部分仍可继续完善。
4. 视频多模态人格预测受数据集、视频质量、语音转写质量和模型泛化能力影响。
5. 系统仍需进一步完善隐私保护、伦理提示和长期使用评估。

### 8.3 后续展望

后续可从以下方向改进：

1. 收集真实测评数据，开展信度、效度和题目参数再校准。
2. 优化 ATMR-CAT 选题策略，进一步平衡题目覆盖、测量精度和用户体验。
3. 引入更丰富的作答行为特征，提升异常检测与可信度建模能力。
4. 完善多模态模型结构，补充更严格的对比实验和跨数据集验证。
5. 强化报告解释中的证据追踪、风险提示和隐私保护机制。
