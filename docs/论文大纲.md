## 第 1 章 绪论

### 1.1 研究背景

介绍在线心理测评、智能问卷系统和人格分析的应用背景。说明传统心理测评在实际使用中常面临题量固定、用户作答状态不可控、报告解释模板化、缺少证据追踪等问题。进一步引出本课题希望构建一个可在线运行、可解释、可追踪、可扩展的智能心理测评系统。

本节可围绕以下内容展开：

1. 在线心理测评系统的发展与应用需求。
2. 自适应测评在减少题量、提高画像效率方面的意义。
3. 异常作答检测与测评可信度表达的必要性。
4. 大模型、RAG 和多智能体方法在报告解释中的辅助价值。
5. 视频多模态人格预测作为问卷测评补充证据链的研究价值。
6. 微表情作为短时非语言视觉线索，在视频多模态分析中的辅助价值与使用边界。

### 1.2 研究意义

从理论和工程两个角度说明课题意义。

理论意义包括：

1. 探索 ATMR 四维测评与自适应选题机制结合的实现方式。
2. 探索将作答行为风险转化为测评可信度的建模方法。
3. 探索问卷测评结果与多模态人格预测结果并列呈现的综合分析框架。
4. 探索将微表情、光流和人脸关键点等细粒度视觉线索作为多模态人格预测辅助特征的工程化路径。

工程意义包括：

1. 实现完整的在线心理测评流程，支持注册登录、答题、报告、历史记录和 AI 咨询。
2. 将自适应选题、异常检测、知识检索、多模态推理和微表情辅助分析集成到可演示系统中。
3. 为后续真实用户数据采集、题库校准、多源证据验证和测评服务迭代提供基础平台。

3. 设计无感知异常作答检测与可信度模型，将作答行为风险转化为题级、维度级和整体级可信度，用于报告解释中的降权提示。
4. 构建 RAG 知识检索与多智能体辩论模块，使报告生成过程能够结合测评结果、知识证据和模块化观点。
5. 接入视频多模态 Big Five 人格预测子系统，完成视频抽帧、音频提取、语音转写、特征提取、模型训练与在线推理闭环。

7. 对系统功能、算法效果、多模态预测结果和微表情辅助线索进行实验验证与结果分析。

## 第 3 章 系统分析与总体设计

### 3.1 需求分析

#### 3.1.1 功能需求

系统应支持：

1. 用户注册、登录和基础资料管理。
2. ATMR 测评创建、草稿恢复、阶段化答题和提交。
3. 自适应选题和作答行为记录。
4. 异常作答检测、可信度计算和报告降权提示。
5. 多智能体分析、RAG 检索和综合报告生成。
6. 视频上传、多模态 Big Five 推理、大五人格报告生成。
7. 微表情特征提取、结果摘要和多模态 feature bundle 扩展。
8. 历史记录、报告详情、聊天咨询和后台质量治理。

#### 3.1.2 非功能需求

系统应具备可维护性、可扩展性、可解释性和边界提示能力。对于多模态和微表情模块，需要明确失败回退、依赖检查、离线训练与在线服务的边界，避免把研究型长任务直接阻塞主系统。

### 3.2 总体架构设计

系统总体由四条能力链组成：

```text
ATMR 问卷主线
-> 作答数据、行为数据、可信度数据
-> 多智能体分析与 RAG 报告
-> ATMR 综合报告

视频多模态辅线
-> 视频、音频、文本特征
-> AGTN-MTL Big Five 推理
-> 大五人格报告

微表情增强线
-> 面部短时运动、光流、关键点
-> MOL 微表情结果
-> 微表情摘要与特征 bundle

咨询交互线
-> ATMR 报告 + 大五人格报告 + 知识库证据
-> AI 咨询上下文
```

综合说明：

1. ATMR 主线已经形成可运行闭环。
2. 视频多模态 Big Five 已完成离线训练、调参、在线 checkpoint 推理和报告接入。

## 第 6 章 总结与展望

### 6.1 本文工作总结

总结系统实现、ATMR-CAT、异常检测、可信度建模、RAG、多智能体、多模态人格预测、微表情辅助模块和实验结果。

### 6.2 创新点与工程价值

可从以下角度归纳：

1. 将 ATMR 问卷测评、自适应选题、可信度降权和 AI 报告生成整合到统一系统。
2. 将视频 Big Five 人格预测作为独立辅助证据链接入主系统。
3. 引入 MOL 微表情 baseline，为多模态人格预测补充细粒度非语言视觉线索。
4. 通过 RAG 与多智能体机制增强报告解释的证据约束。

### 6.3 不足与后续工作

需要诚实说明：

1. ATMR 题库参数仍依赖模拟冷启动校准，后续需要更多真实用户数据。
2. 多模态 Big Five 当前是工程化 baseline，尚未完全复现参考论文中的全部多任务损失和关联特征设计。
3. 微表情当前基于公开 TIM20 数据包 quick baseline，官方授权数据上的严格复现尚待完成。
4. 多源证据目前以并列解释和辅助一致性为主，尚未形成经过真实用户验证的强融合心理测评模型。
5. 后续可继续补充真实用户实验、授权微表情数据、正式消融实验和更规范的后台任务队列。
